# Trackpad Sensor Monitor

即時顯示 Trackpad 感測器數據的桌面監控程式。

## 版本紀錄

### v1.2.4

- 感測器圖新增縮放與平移：滑鼠滾輪以游標為中心縮放（1x–5x），數值與校正文字會隨縮放大小調整
- 放大時可按住右鍵或中鍵拖曳平移；雙擊右鍵或中鍵可重設縮放與平移
- 左下角新增縮小／放大／重設按鈕
- 修正縮放按鈕邊緣被裁切的問題

### v1.2.3

- 新增 64x 與 128x 的 ADC 增益選項
- 新增 P4 V2R 16x16 感測器版面

### v1.2.2

- 修正標籤（QLabel）背景，改為透明，面板上不再出現較深色的底框
- 更新 p4v2 版面的感測器對應圖為鏡像方向

### v1.2.1

- 記住上次使用的型號、COM 埠、鮑率與錄製資料夾，下次啟動時自動帶入

### v1.2.0

- 新增原始數據錄製：以「Record」按鈕將每個接收到的影格串流寫入 CSV
- CSV 檔頭記錄 metadata（型號、版面位置、增益、基準值），後接 `t_ms` 與依裝置順序排列的各感測器欄位
- 斷線、切換型號或關閉程式時自動停止錄製

### v1.1.0

- 新增校正（Calibration）最小／最大值，並在統計表加入 Calib 欄位
- 摘要統計僅計入實際放置於版面圖上的感測器
- 統計表與 CSV 匯出排除不在版面圖上的感測器

### v1.0.0

- 首個正式版本
- 啟動時檢查 GitHub Releases 是否有新版本，更新對話框提供連結與「稍後」按鈕
- 支援電阻值顯示；未校正的基準值以 NaN 處理
- 新增應用程式圖示
- 視窗標題與打包輸出（exe 名稱、zip）帶有版本號
- 感測器版面由 JSON 檔載入，優先使用使用者可編輯的版面目錄
- 感測器熱圖、校正格顯示、裝置 ID 顯示、ADC 增益與閒置值處理
